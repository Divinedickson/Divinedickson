## Featured projects

### 📚 Academic Research Assistant

**Upload a paper. Ask a question. Follow the evidence.**

A full-stack research application that lets users ask questions about uploaded papers and receive answers with source citations.

- Django REST API and React frontend with JWT authentication.
- PDF processing, text chunking, and semantic retrieval using PostgreSQL and pgvector.
- Source citations and bounded context to connect answers to the uploaded documents.

**Built with:** Python · Django REST Framework · React · PostgreSQL · pgvector

[Explore the repository →](https://github.com/Divinedickson/academic-research-assistant)

### 🌿 Plant Disease Detector

**From a leaf image to a useful prediction.**

A web application that classifies plant diseases from uploaded leaf images, connecting a trained model to a usable frontend and backend.

- Image classification across 38 PlantVillage classes.
- React interface backed by Django.
- Confidence thresholds that flag uncertain predictions.

**Built with:** Python · Django · React · Deep Learning

[Explore the repository →](https://github.com/Divinedickson/plant-disease-detector)
